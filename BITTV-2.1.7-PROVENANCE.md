## Source and publisher status

The APK was downloaded from the third-party page [bittvapk.app](https://bittvapk.app/apk/), which advertises version 2.1.7 and names “Duktek Digital TV.” The independent [Appteka listing](https://appteka.store/app/f57r331535) labels it a MOD, lists version `2.1.7-new-obsidian`, and identifies Yadi Fernando as the modder. The APK downloaded from Appteka was byte-for-byte identical to the file from bittvapk.app (matching SHA-256 above).

No official BitTV publisher release or verified publisher identity was established. The bittvapk.app page listed a size of 7.95 MB, which does not match the downloaded file size; another listing reports approximately 29.79 MiB.

## Scan evidence and limits

The Appteka listing labels the build “Verified safe” and says it was scanned with ClamAV, APKiD, and Quark-Engine with no threats detected. Its hosted APK was confirmed byte-identical to this file by SHA-256. This records Appteka's claim, not a guarantee of safety.

[URLScan's report for the same SHA-256](https://urlscan.io/sha256/7481ae0da546654573c7ece7318cff3d4091ae1bd3a1e396be8891bb066e2b35/) has no classification. Its linked scan is a single download observation and is not a malware-clean verdict. No official publisher verification or definitive independent safety verdict was obtained.
